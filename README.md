# Sales Performance Analysis

## Project Overview

This project analyzes sales and financial performance to identify trends, compare product and country performance, and understand profitability across different discount bands.

## Tools and Technologies

* Python — Data cleaning and preparation
* SQL (MySQL) — Data analysis and business queries
* Power BI — Interactive dashboard and data visualization
* Excel — Data review and analysis

## Dataset Description

The dataset contains 700 records and 16 columns, covering September 2013 to December 2014. It includes sales, profit, discounts, units sold, products, countries, business segments, and dates.

## Data Cleaning

* Standardized column names.
* Converted the date column to datetime format.
* Handled 53 missing discount-band values by assigning them to the `None` category.
* Checked for duplicate records.
* Verified missing values after cleaning.

## Key Findings

* Total Sales: approximately $118.73 million
* Total Profit: approximately $16.89 million
* Overall Profit Margin: approximately 14.23%
* The Medium discount band generated the highest total sales.
* The Low discount band generated the highest total profit among the discounted categories.

## Power BI Dashboard

The interactive dashboard presents:

* Total Sales, Total Profit, Total Units Sold, and Profit Margin KPIs
* Sales trends over time
* Product and country comparisons
* Profit by discount band
* Year, month, country, and discount-band slicers

## Business Recommendations

* Review discount strategies to balance sales and profitability.
* Monitor product and country performance.
* Track monthly and yearly sales trends.
* Use interactive dashboards to support data-driven decisions.

## Conclusion

This project demonstrates the use of Python, SQL, Excel, and Power BI to clean sales data, analyze business performance, and communicate findings through an interactive dashboard.
